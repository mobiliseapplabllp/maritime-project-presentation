# Sagar Drishti — "talk to the documents" knowledge library

Curated maritime corpus + BM25 chunk index behind the portal's DOCUMENT chat
mode (`portal/backend/app/rag.py`). This replaced the POSHAN-era harvested
library: the old `harvest_docs.py` web scraper is gone; the corpus is now
authored/curated in-repo.

## Layout

```
data/knowledge/
├── docs/
│   ├── port_circulars/   6 docs — the Mundra Operations Portal's own demo-world
│   │                     instruments (notices, circulars, ISPS order). The
│   │                     refNos, dates, register summaries and bodies are canon
│   │                     from portal/backend/scripts/seed.js (Instrument seed),
│   │                     expanded into full circular-style documents. The two
│   │                     superseded instruments (CIRC-04/2025, CIRC-03/2023)
│   │                     are quoted verbatim inside their successors
│   │                     (PORT-N-07/2026 §6, CIRC-12/2026 §5).
│   ├── reference/        10 docs — plain-language summaries of real public
│   │                     instruments (MS Act 1958, Indian Ports Act 1908, Major
│   │                     Port Authorities Act 2021, SOLAS, MARPOL I–VI, ISPS,
│   │                     MLC 2006, STCW + MS STCW Rules 2014, PSC Indian Ocean
│   │                     MoU, IMO FAL). Every file is headed "Reference summary
│   │                     compiled from public sources for the Sagar Drishti
│   │                     demo library" — own words, no quoted legal text.
│   └── mundra_sops/      4 docs — demo-world SOPs authored for the port:
│                         MP-01 pilotage & towage, MP-02 bunkering checklist,
│                         MP-03 monsoon restrictions, MP-04 oil-spill Tier-1.
│                         Consistent with the seeded world (VHF Ch 12 pilotage
│                         working channel, 20% monsoon UKC at WB-1/WB-2,
│                         MARSEC 1 / Gate 3 shore leave, tug fleet, Okha CG).
├── manifest.json         [{id,title,url,source,category,fetched,size_kb}] —
│                         regenerated by curate_docs.py; rag.status() counts it.
├── curate_docs.py        The corpus catalog → manifest.json (no web fetching).
├── build_index.py        Unchanged generic builder: docs/ + manifest.json →
│                         index/chunks.json (+meta.json). ~1600-char chunks,
│                         200 overlap; markdown/txt read as page 1.
└── index/
    ├── chunks.json       [{doc,title,url,source,category,page,text}] — the
    │                     exact shape rag.py loads (BM25, title terms ×4).
    └── meta.json         {retrieval, chunks, docs, built, skipped}
```

Current build: 20 docs, ~72 KB of text, 61 chunks.

## Rebuild

```bash
cd data/knowledge
python3 curate_docs.py    # docs/ catalog -> manifest.json
python3 build_index.py    # -> index/chunks.json + index/meta.json
```

The backend picks the new index up on restart or via `rag.reload_index()`.
Embeddings are optional (only written if a local Ollama happens to run);
the chunk index alone fully serves the portal.

## Content rules

- Demo-world documents (port_circulars, mundra_sops) each carry a header
  stating they are fictional Mundra Operations Portal instruments, and their
  dates align to the August 2026 demo snapshot (seed dates are relative to
  seed time, so exact days may drift a little across reseeds).
- Reference documents summarise real public instruments in the library's own
  words and are labelled as summaries — no fabricated quotations.
- No misconduct is attributed to real companies or vessels anywhere in the
  corpus.
- Adding a document: drop the .md under docs/<category>/, add its row to
  CATALOG in curate_docs.py, rerun the two commands above. Keep the corpus
  modest (< 400 KB total) so BM25 stays sharp and chunks stay on-topic.
