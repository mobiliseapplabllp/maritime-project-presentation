the note names the nearest replacement where one exists. Endpoint PATHS are
unchanged throughout; only JSON keys, query/body parameter names and enum values
listed here changed. Produced by the backend sweep of analytics.py, records.py,
sections.py, qa.py, yearbook.py, research.py, finding_details.py, datasets.py,
pg_query.py, mailer.py, twins_lib.py, main.py.

## Notes for the frontend sweep
- All /api/records/* record-link types keep their route ids (asset=vessel, ticket=incident, pm=inspection, employee=seafarer, facility=berth, district=terminal); only labels should change in the UI.
- analytics.py still passes a legacy `district=` keyword to workorders.list_orders inside a try/except TypeError fallback, and files a legacy `district` copy in the create payload — remove both once workorders.py's own re-domain lands.
- pg_query.run_select now targets the in-memory SQLite analytics mirror (SQLite dialect; tables ops/marine/hse/revenue/unit_latest/vessel_reliability/vessel_watchlist/hotspot_ranking/terminal_trends). No Postgres anywhere in the re-domained files.
- research articles now persist in agent_state/research_articles.json; the Postgres research_articles table is unused by these files.
